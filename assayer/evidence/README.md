# Evidence

Test records and controls for the assayer skill. Kept because the rules in `SKILL.md`
are only worth what the tests behind them are worth, and a rule whose baseline was
never run is an opinion.

| File | What it is |
| --- | --- |
| `distinctiveness-test.md` | RED/GREEN record for "the exemplar is the floor", plus the two briefs that located where slop actually comes from |
| `thin-brief-control.html` | The raw control output: what a model produces from "a modern landing page for my SaaS startup, make it look really good". Open it in a browser |
| `thin-brief-control.jpg` | The same page rendered, for anyone not opening the HTML |
| `assay-report.html` | A standalone report on the skill — the method, the controls, the findings, and the properties that demonstrably fail |

The control is worth keeping in full rather than summarising. Every trope is in it —
gradient headline, glassmorphism, radial glow, fake browser chrome, logo strip, six-card
grid, numbered steps, stats row, testimonial, three pricing tiers, FAQ accordion — and so
are six fabricated claims presented as fact.
